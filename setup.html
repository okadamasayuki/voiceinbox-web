はじめかた — 鍵の作り方

この画面を使うには、GitHub で「鍵」（fine-grained personal access token）を 1 つ作ります。7 手順、5 分ほどです。
鍵は端末ごとに 1 つずつ作ってください（会社のパソコン・自宅のパソコン・iPhone）。

1GitHub の右上のアイコンから Settings を開く

リポジトリの Settings ではありません。アカウントの Settings です。GitHub のどのページからでも、右上の丸いアイコンを押すと出てきます。

GitHub
Your profile
Your repositories
⚙️ Settings
Sign out

右上のアイコン → メニューの下のほうにある Settings

2左のメニューをいちばん下まで送り、Developer settings を開く

項目が多いので、見つからないときはページの最下部までスクロールしてください。

Account settings
Public profile
Account
Appearance
・・・ 途中の項目は省略 ・・・
Applications
Scheduled reminders
</> Developer settings

左メニューのいちばん最後にあります

3Personal access tokens → Fine-grained tokens を選ぶ

Tokens (classic) ではありません。classic は「どのリポジトリにも効く鍵」になってしまうので使いません。

Developer settings
GitHub Apps
OAuth Apps
Personal access tokens ▾
Fine-grained tokens Tokens (classic)
Generate new token

Fine-grained tokens のほうを選び、Generate new token を押します

4名前・期限・所有者を決める

  • Token name … どの端末の鍵か後で分かる名前にします（例: 会社PC / 自宅PC / iPhone）。
  • Expiration … 有効期限。90 日くらいが扱いやすいです。期限が来たら作り直します。
  • Resource owner … 自分のアカウントを選びます。
New fine-grained personal access token
Token name
会社PC
Expiration
90 days
Resource owner
（自分のアカウント）

期限を書き留めておくと、VoiceInbox の設定画面に入れて残り日数を表示できます

5Repository access で「Only select repositories」を選ぶ

そのうえで、メモを保存するリポジトリ 1 つだけを指定します。ここがいちばん大事なところです。

Repository access
Public repositories (read-only)
Only select repositories
選んだリポジトリだけに効く鍵になります
All repositories
Select repositories
（メモ用のリポジトリを 1 つ）

All repositories は選ばないでください

6Repository permissions で Issues だけを Read and write にする

権限の一覧はとても長いですが、触るのは Issues の 1 行だけです。Metadata は自動で Read-only が付きます。ほかはすべて No access のままにしてください。

Repository permissions
ActionsNo access
ContentsNo access
IssuesRead and write
MetadataRead-only（自動）
Pull requestsNo access
・・・ ほかの項目はすべて No access のまま ・・・

Issues の権限にはラベルの読み書きも含まれます。送信先の一覧はここから作られます

7表示された文字列をコピーする

Generate token を押すと、github_pat_ で始まる長い文字列が一度だけ表示されます。これが鍵です。

Personal access tokens (fine-grained)
github_pat_••••••••••••••••••••••••••••••••••••••••••••••••••••••••••••
（実際には英数字の長い文字列が表示されます）
📋 Copy

この画面を閉じると二度と表示されません

コピーしたら VoiceInbox の画面 にもどって、オーナー名・リポジトリ名とあわせて貼り付けてください。

注意すること

All repositories は選ばないこと 手順 5 で All repositories を選ぶと、その鍵は自分のすべてのリポジトリに効いてしまいます。万一漏れたときの被害範囲がまったく変わります。必ず Only select repositories で 1 つだけ指定してください。
鍵は作成直後の 1 回しか表示されません 画面を閉じると二度と見られません。表示されたその場で、パスワードマネージャに保存してください。控え忘れたときは、作り直せば済みます（古いほうは Delete してください）。
端末ごとに別の鍵を作ってください 会社のパソコン・自宅のパソコン・iPhone で別々の鍵にしておくと、その端末の鍵だけを無効にできます。1 つを使い回すと、全部を作り直すことになります。
期限切れでメモが消えることはありません 鍵の期限が切れると画面は読み込めなくなりますが、メモそのものは GitHub に残っています。新しい鍵を作って貼り直せば、そのまま元にもどります。
無効にしたいとき Fine-grained tokens の一覧から、その鍵の Delete を押します。すぐに効きます。端末を紛失したときは、まずこれを行ってください。

よくあるつまずき

「リポジトリが見つからないか、鍵の権限が足りていません」と出る

次の 3 つを順に確かめてください。①オーナー名とリポジトリ名の綴り（大文字小文字は区別しません）。②手順 5 でそのリポジトリを選び忘れていないか。③手順 6 で Issues が Read and write になっているか。fine-grained token は、指定していないリポジトリに対しては「存在しない」という応答になります。

「鍵の期限が切れているか、無効になっています」と出る

期限切れか、鍵を Delete したときに出ます。手順 1 からもう一度作り直して、設定画面の「鍵を入れ直す」に貼ってください。メモは消えていません。

Tokens (classic) で作ってしまった

classic の鍵（ghp_ で始まるもの）は、リポジトリを 1 つに絞れません。手順 3 にもどって Fine-grained tokens のほうで作り直し、classic のほうは Delete してください。

会社のパソコンで使ってよいか不安

接続先は GitHub だけで、こちらから通信を受ける口は開きません。そのうえで、最初の画面の「このパソコンを保護する」をオンにしてください。鍵がパスフレーズで暗号化され、10 分操作しないと自動でロックします。離席時の画面のぞき見にも効きます。

鍵はどこに保存されるのか

このページを開いているブラウザの中（localStorage）だけです。ページを配信しているサーバーには送られません。「このパソコンから削除」を押せば、その端末から消えます。
